# ADR-0003 — Emulate NTAG213 (MIFARE Ultralight)

## Context

NFC emulation needs a target tag type. Options include NTAG21x, MIFARE Classic,
and Type-4 (NDEF over ISO14443-4).

## Decision

Emulate **NTAG213** (MF Ultralight, ISO14443-3A) with a capability container and
an NDEF TLV in user memory.

## Consequences

- Universally readable by phones; no sector/auth complexity.
- 144 B user memory is plenty for a URL.
- Directly supported by the firmware `nfc` listener (`NfcProtocolMfUltralight`).
- Limited capacity (not suitable for large vCards) — acceptable.
